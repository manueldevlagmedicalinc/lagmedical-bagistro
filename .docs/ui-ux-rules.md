# UI UX Rules

## Objective

Support B2B procurement workflows.

## Priority

1. Product discovery
2. Technical information
3. RFQ generation
4. Trust building

## Design Principles

Use:

- Clean layouts
- Clear navigation
- Fast access to specifications

Avoid:

- Retail gimmicks
- Excessive animations
- Distractions

## Product Pages

Prioritize:

- Specifications
- Documents
- Brochures
- Manufacturer information

## Forms

Keep forms:

- Simple
- Fast
- Business focused
