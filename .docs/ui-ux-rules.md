# UI UX Rules

## Objective

Support B2B procurement workflows.

## Priority

1. Product discovery
2. Technical information
3. RFQ generation
4. Trust building

## Design Principles

Use:

- Clean layouts
- Clear navigation
- Fast access to specifications

Avoid:

- Retail gimmicks
- Excessive animations
- Distractions

## Product Pages

Prioritize:

- Specifications
- Documents
- Brochures
- Manufacturer information

## Forms

Keep forms:

- Simple
- Fast
- Business focused



## UI Customization Rule

Never edit files inside:

packages/Webkul/*

All visual modifications must be implemented inside the Lag Medical theme.

Use:

- Theme overrides
- Custom Blade components
- Custom Tailwind components
- Theme-specific assets

Do not modify:

- Webkul views
- Webkul layouts
- Webkul Vue components
- Webkul assets

The active theme must contain all UI customizations.
