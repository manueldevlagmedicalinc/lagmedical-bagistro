# Infrastructure Rules

## Environment

Current stack:

- Ubuntu
- OpenLiteSpeed
- CyberPanel
- MySQL
- PHP 8.3
- Wasabi Storage

## Deployment

Prefer:

- Git deployments
- Controlled releases
- Rollback capability

Avoid:

- Manual production edits

## Storage

Verify:

- Ownership
- Permissions
- Symlinks

Before changing storage paths.

## Performance

Prioritize:

- Cache
- Queue workers
- Image optimization

## Monitoring

Verify:

- Logs
- Failed jobs
- Disk usage
- Database health
