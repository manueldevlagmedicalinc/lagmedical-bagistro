# SEO and AEO Rules

## Objective

Optimize for:

- Google
- Bing
- ChatGPT
- Gemini
- Copilot
- AI Answer Engines

## Content Structure

Always prefer:

- Clear headings
- Semantic structure
- FAQ sections
- Entity relationships

## Product Pages

Prioritize:

1. Manufacturer
2. Brand
3. Model
4. Category
5. Specifications
6. Applications

## Metadata

Every page should support:

- Title
- Meta Description
- Canonical URL

## AI Visibility

Content should answer:

- What is it
- Who uses it
- Why it matters
- Technical specifications
- Related entities

## E-E-A-T

Prioritize:

- Accuracy
- Expertise
- Authority
- Trust
